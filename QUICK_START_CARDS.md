# ⚡ Быстрый старт: Настройка выплат на карту

## Что нужно сделать СЕЙЧАС

### 1️⃣ Откройте страницу настроек

```
http://localhost:3000/settings
```

Прокрутите вниз до раздела **"Ключи шифрования карт"**

### 2️⃣ Загрузите публичные ключи через UI

**Для PRE окружения:**
1. Нажмите "Загрузить ключ" под карточкой PRE
2. Откройте документацию Cyclops → раздел "Шифрование номера карты"
3. Скопируйте публичный ключ для PRE (или загрузите файл `pre.pem`)
4. Вставьте ключ в форму
5. Нажмите "Сохранить"

**Для PROD окружения:**
1. Повторите те же шаги для карточки PROD
2. Используйте ключ для PROD окружения (или файл `prod.pem`)

### 3️⃣ Альтернатива: через .env.local (если нужно)

Если предпочитаете использовать переменные окружения:

```bash
# В файле .env.local
CYCLOPS_CARD_PUBLIC_KEY_PRE="-----BEGIN PUBLIC KEY-----
(ВСТАВЬТЕ СЮДА ВЕСЬ КЛЮЧ ДЛЯ PRE)
-----END PUBLIC KEY-----"

CYCLOPS_CARD_PUBLIC_KEY_PROD="-----BEGIN PUBLIC KEY-----
(ВСТАВЬТЕ СЮДА ВЕСЬ КЛЮЧ ДЛЯ PROD)
-----END PUBLIC KEY-----"
```

Затем перезапустите сервер:
```bash
npm run dev
```

### 4️⃣ Проверьте что работает

1. Откройте http://localhost:3000/deals/new
2. Выберите тип получателя "На карту"
3. Введите тестовый номер карты: `4111 1111 1111 1111`
4. Заполните остальные поля
5. Нажмите "Создать сделку"

✅ Если все настроено правильно - сделка создастся без ошибок!

## Проблемы?

### Ошибка "Публичный ключ не настроен"
→ Проверьте что в `.env.local` есть переменные `CYCLOPS_CARD_PUBLIC_KEY_PRE` и `CYCLOPS_CARD_PUBLIC_KEY_PROD`

### Ошибка "Invalid key format"
→ Убедитесь что скопировали ключ целиком с `-----BEGIN PUBLIC KEY-----` и `-----END PUBLIC KEY-----`

### Сервер не видит новые переменные
→ Перезапустите `npm run dev`

### Номер карты не принимается
→ Номер должен содержать от 13 до 19 цифр (можно с пробелами, они будут удалены автоматически)
