# Настройка шифрования номеров карт для Cyclops

## Проблема

При создании сделки с получением на карту возникает ошибка:
```
Unexpected token '<', "<!DOCTYPE "... is not valid JSON
```

Это происходит потому, что отсутствует API endpoint `/api/encrypt-card` для шифрования номеров карт.

## Решение

### 1. Установка публичных ключей шифрования

Публичные RSA ключи Cyclops необходимы для шифрования номеров карт перед отправкой в API.

**Способ 1: Через веб-интерфейс (рекомендуется) ✨**

1. Откройте страницу настроек: `http://localhost:3000/settings`

2. Найдите раздел **"Ключи шифрования карт"**

3. Для каждого слоя (PRE и PROD):
   - Нажмите кнопку "Загрузить ключ"
   - Скопируйте публичный ключ из документации Cyclops (раздел "Шифрование номера карты")
   - Вставьте ключ в текстовое поле ИЛИ загрузите PEM файл
   - Нажмите "Сохранить"

4. Ключи будут сохранены в `.keys/card-encryption/` и автоматически использоваться при создании сделок!

**Способ 2: Переменные окружения**

1. Скачайте публичные ключи из документации Cyclops:
   - **Pre окружение** (тестовое) - файл `pre.pem` или скопируйте из документации
   - **Prod окружение** (продакшен) - файл `prod.pem` или скопируйте из документации

2. Откройте PEM файл в текстовом редакторе и скопируйте содержимое целиком (включая строки `-----BEGIN PUBLIC KEY-----` и `-----END PUBLIC KEY-----`)

3. Добавьте их в `.env.local`:

```bash
# Публичный ключ для pre окружения
CYCLOPS_CARD_PUBLIC_KEY_PRE="-----BEGIN PUBLIC KEY-----
MIICIjANBgkqhkiG9w0BAQEFAAOCAg8AMIICCgKCAgEA...
-----END PUBLIC KEY-----"

# Публичный ключ для prod окружения
CYCLOPS_CARD_PUBLIC_KEY_PROD="-----BEGIN PUBLIC KEY-----
MIICIjANBgkqhkiG9w0BAQEFAAOCAg8AMIICCgKCAgEA...
-----END PUBLIC KEY-----"
```

**Способ 2: Жестко закодировать в коде (не рекомендуется)**

Отредактируйте файл `lib/crypto.ts` и замените заглушки на реальные ключи:

```typescript
export const CYCLOPS_CARD_PUBLIC_KEYS = {
  pre: `-----BEGIN PUBLIC KEY-----
  ... ваш реальный ключ для pre ...
  -----END PUBLIC KEY-----`,
  prod: `-----BEGIN PUBLIC KEY-----
  ... ваш реальный ключ для prod ...
  -----END PUBLIC KEY-----`,
};
```

### 2. Перезапуск сервера

После добавления ключей перезапустите Next.js сервер:

```bash
# Остановите текущий процесс (Ctrl+C)
# Запустите снова
npm run dev
```

### 3. Проверка работы

1. Откройте страницу создания сделки: http://localhost:3000/deals/new
2. Выберите тип получателя "На карту"
3. Заполните номер карты (16 цифр)
4. Заполните остальные поля
5. Нажмите "Создать сделку"

Если настройка выполнена правильно, номер карты будет зашифрован перед отправкой в API.

## Архитектура

### Поток шифрования:

```
┌─────────────────────────────────────────────────┐
│ 1. Форма создания сделки (DealForm.tsx)        │
│    - Пользователь вводит номер карты           │
│    - Номер хранится в state как plain text     │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│ 2. Отправка на шифрование                      │
│    POST /api/encrypt-card                      │
│    Body: { card_number: "1234567890123456" }   │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│ 3. Серверное шифрование (route.ts)             │
│    - Получение публичного ключа из env         │

│    - Кодирование в base64                      │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│ 4. Возврат зашифрованных данных                │
│    Response: {                                  │
│      card_number_crypto_base64: "..."          │
│    }                                            │
└─────────────────┬───────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────┐
│ 5. Отправка в Cyclops API                      │
│    Поле card_number_crypto_base64 вместо       │
│    открытого номера карты                      │
└─────────────────────────────────────────────────┘
```

2. **`app/(dashboard)/deals/[dealId]/components/DealRecipients.tsx`** (исправлен)

   - Добавлены примеры переменных для публичных ключей
   - Документация по использованию

## Безопасность

- ✅ Номера карт шифруются на сервере (не в браузере)
- ✅ Используется RSA-OAEP с SHA-256 (стандарт Cyclops)
- ✅ Публичные ключи безопасно хранятся в переменных окружения
- ✅ Открытые номера карт не сохраняются в базе данных
- ✅ Зашифрованные данные передаются только в Cyclops API

## Получение публичных ключей

**Публичные ключи предоставлены в документации Cyclops** в разделе "Шифрование номера карты".

Вы должны получить два PEM файла:
- `pre.pem` - для тестового окружения
- `prod.pem` - для продакшен окружения

📖 **Подробная инструкция по установке:** [KEYS_INSTALLATION_GUIDE.md](./KEYS_INSTALLATION_GUIDE.md)

Если не можете найти ключи в документации, свяжитесь с технической поддержкой:
- Email: support@tochka.com
- Укажите: "Нужны публичные RSA ключи для шифрования номеров карт (payment_contract_to_card)"

## Поддержка

Если после настройки проблема сохраняется:

1. Проверьте логи сервера в консоли
2. Откройте DevTools → Network → проверьте ответ от `/api/encrypt-card`
3. Убедитесь что публичные ключи загружены корректно (должны содержать реальные данные, а не "...")
